Zindex quick start

  cargo build --release --locked

Build an index of the bundled bacterial genomes:
  ./target/release/zorindex build --fof tests/data/bacteria/samples.fof \
    --output bacteria.zindex --k 31

Query one sequence:
  ./target/release/zorindex query --index bacteria.zindex \
    --query tests/data/bacteria/query.fa

Report each query separately:
  ./target/release/zorindex query --index bacteria.zindex \
    --query tests/data/bacteria/queries.fa --records --min-ratio 0.8

Index minimizers instead:
  ./target/release/zorindex build --fof tests/data/bacteria/samples.fof \
    --output bacteria.min.zindex --k 31 --index-mode minimizers --window 19

Use your own FASTA/FASTQ paths in place of the bundled samples.fof.
Query settings are automatically read from the index.
See docs/USAGE.md for the remaining seed and query options.
